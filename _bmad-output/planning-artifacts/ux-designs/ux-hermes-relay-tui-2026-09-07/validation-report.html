Accessibility review

review-accessibility.md

The confirmed boundaries are correct, but accessibility sign-off is blocked by state-language mapping, assistive semantics, contrast, room-distance readability, profile visibility, privacy lifecycle, and recovery affordances. Findings below retain the reviewer’s severity.

high

Close the state-language contract

EXPERIENCE.md §State Patterns
Child-facing `working`, `unavailable`, and `stopped` do not have a normative mapping to the shared protocol vocabulary, technical detail, visual cue, sound cue, or screen-reader announcement.
Fix: Add one matrix separating protocol states from primary child-readable labels and technical Client/TUI detail.
high

Define assistive technology and focus behavior

EXPERIENCE.md §Accessibility Floor
The iPad path uses a canvas, while the mock’s labels do not expose changing state or response text. iOS focus and action semantics are also open.
Fix: Require an accessible DOM/status mirror, announce state changes once, expose identity and recovery status, and define iOS focus return plus keyboard/terminal equivalents.
high

Make contrast pairs compliant

DESIGN.md §Colors
Identity foreground, emphasis border, and subtle border pairs do not meet the claimed text or non-text targets.
Fix: Reassign or change semantic pairs and test actual text and component combinations; retain redundant labels and shapes.
high

Make room-distance readability testable

DESIGN.md §Typography / §Layout
Utility labels are small and dense, and no minimums identify which state, profile, response, error, and recovery text remains readable at roughly two metres.
Fix: Add real-device distance tests and minimums; keep small labels supplementary.
high

Show Profile identity before capture

EXPERIENCE.md UJ-1 / DESIGN.md §Brand & Style
The source fixes identity before capture, but the design says identity appears when a response is visible while UJ-1 shows it during acknowledgement/listening.
Fix: Commit the earliest identity phase and keep the fixed profile visible on the owning visual surface through completion.
high

Specify the no-history lifecycle

EXPERIENCE.md §Privacy / §State Patterns
Shared devices may cache active context, but the spines do not define clearing, browser storage, reboot, reconnect hydration, or partial-text purge boundaries.
Fix: State that shared conversation text is volatile active-turn state only, never persisted or rehydrated; define the terminal and purge boundaries.
high

Assign Retry and stale-context behavior to surfaces

EXPERIENCE.md §Recovery / §Responsive & Platform
Retry appears in the component contract, but v1 room Displays have no visible touch action and cached calendar freshness is unspecified.
Fix: Make Retry iOS/TUI-only or define an advertised Display capability; distinguish disconnected, unavailable identity, generic error, and audio unavailable.
medium

Close the cue and quiet/night contract

EXPERIENCE.md §Interaction Primitives
Cue meaning, duration, volume, suppression, visual equivalents, and quiet/night behavior remain open.
Fix: Add a cue table and quiet/night preference; sound-off must leave every state understandable from text.
medium

Make reduced motion an explicit static presentation

DESIGN.md §Voice Visualizer / EXPERIENCE.md §Accessibility
The mock shortens animation duration but does not define the static replacement.
Fix: State a no-animation rule for every active state and test `prefers-reduced-motion`.
medium

Protect text over ambient media

DESIGN.md §Ambient Surface / §Departure Card
Arbitrary Immich imagery can compromise event, countdown, and status legibility.
Fix: Require a controlled contrast treatment or opaque card behind every load-bearing field and test bright and dark photos.
medium

Validate child comprehension

EXPERIENCE.md §Accessibility Floor
Technical vocabulary such as `Transcribing`, `Disconnected`, `Profile`, and `Turn Path` has no comprehension test or language policy.
Fix: Test labels and recovery choices with representative child users; keep technical diagnostics secondary and state supported languages.

Editorial prose review

review-prose.md

Eleven copy-edit recommendations: ten definitive clarity fixes and one wording option. They are approximately word-neutral and preserve the dense instrument-panel voice, state vocabulary, tables, and named journey beats.

low

Clarify the relationship sentence

DESIGN.md §Brand & Style
“Hermes is the product relationship.” is abstract.
Fix: Consider: “Hermes is the shared relationship across doorways.”
low

Name failure information explicitly

EXPERIENCE.md §Voice and Tone
“It must never obscure privacy, identity, or a failure.” has an awkward singular noun.
Fix: Use “privacy, identity, or failure information.”
low

Clarify Profile Header ownership

EXPERIENCE.md §Component Patterns
The pronoun in “proof that” is ambiguous.
Fix: Use “The header must not imply that the answer is correct; Hermes owns the answer content.”
low

Make follow-up timing parallel

EXPERIENCE.md §Follow-up Window / §Interaction Primitives
The opening and closing actions have different grammatical shapes.
Fix: Use “When the window opens, play a sound cue and show Listening again; when it closes without new speech, play the closing cue.”
low

Repair the complete-state sentence

EXPERIENCE.md §State Patterns
“No follow-up ends with…” is unclear.
Fix: Split it into two sentences naming the expiry condition and return state.
low

Use a complete child-readable list construction

EXPERIENCE.md §Accessibility Floor
“The child-readable set is…” is less clear than an inclusive construction.
Fix: Use “The child-readable set includes…”
low

Remove memlog meta-language from accessibility prose

EXPERIENCE.md §Accessibility Floor
“The captured decision keeps them…” is not meaningful to a finished-spine reader.
Fix: Use “Sound cues remain available as a turn-taking aid.”
low

Prefer “shows” to “exposes” for reader-facing states

EXPERIENCE.md §Interaction Primitives / UJ-1
The current verb sounds like an internal API rather than a user-visible behavior.

low

Make `stop` an explicit user utterance

EXPERIENCE.md §Interaction Primitives / State Patterns / UJ-1

low

Clarify the transport-loss transition

EXPERIENCE.md §Recovery

Fix: Use “A transport loss during a turn moves the doorway to `Disconnected State`…”

Repair the open-question noun phrase

EXPERIENCE.md §Open Questions
“follow-up close” is not a natural parallel phrase.
